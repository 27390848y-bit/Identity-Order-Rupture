# 01 — Project Brief

## Project Title
Personal Digital Identity — ORDER / RUPTURE

## Project Context
The project was developed as part of an AI and Design course.

The assignment focuses on creating a personal digital identity and translating it into a single-page website.

## Initial Concept
The visual identity explores the relationship between two opposing principles:

- ORDER — structure, precision, organization and systems.
- RUPTURE — disruption, deviation and breaking established patterns.

## Design Background
The initial visual material was developed as an A0 poster in Figma.

The poster became the starting point for developing a digital identity and a web-based composition.

## Initial Decisions
- Preserve the original A0 poster.
- Create a separate Figma frame named WEB — IDENTITY.
- Set the web frame dimensions to 1440 × 1200 px.
- Adapt the original composition to the new frame.
- Maintain a single-page website concept.

## Project Goal
Create a single-page personal identity website that combines visual design, professional identity, personal interests and design thinking into one integrated composition.

## Development Approach
The project will be developed using Figma, HTML, CSS and GitHub.

GitHub will also serve as a platform for documenting the design and development process.
