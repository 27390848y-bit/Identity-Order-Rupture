# PERSONAL IDENTITY — ORDER / RUPTURE

## Project Overview

This project explores the creation of a personal digital identity through a single-page website.

The visual concept is based on the tension between two opposing principles:

- **ORDER** — structure, precision, grids, systems and organization.
- **RUPTURE** — disruption, deviation, irregularity and questioning established systems.

The website translates an existing visual identity poster into a digital experience.

## Project Objectives

- Develop a personal visual and digital identity.
- Translate an existing Figma composition into a functional website.
- Explore the relationship between graphic design, architecture and technology.
- Document the design and development process.
- Use GitHub for documentation and website publishing.

## Tools

- Figma — visual design and composition.
- HTML — website structure.
- CSS — visual styling.
- GitHub — project repository and documentation.
- GitHub Pages — website publishing.

## Design Approach

The project is not intended to be a conventional portfolio or business card. It is conceived as a visual representation of personal identity, professional practice and design thinking.

The final outcome will be a single-page website in which all elements form one integrated composition.
